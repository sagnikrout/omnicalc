# Original Python Prototype (The Origin)

This directory preserves the original Python prototype created by **Sagnik Rout** ([@sagnikrout](https://github.com/sagnikrout)) when the project was first conceived at [https://github.com/sagnikrout/cal](https://github.com/sagnikrout/cal).

## Original Vision Note
> "Test and help to develop a command line yet powerful calculator  
> It is in it's version 2 in this stage.  
> Though this is a primary stage yet we are trying to achieve our goal.  
> And I hope we will continue to evolve  
> development mainly by SagnikRout"

## Evolution
This prototype laid the intellectual foundation and ambition that evolved into `omnicalc`: the sub-millisecond, arbitrary-precision, physical dimensional Rust engine.
